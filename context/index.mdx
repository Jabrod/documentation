<Note>Context is available at [jabrod.com/app/context](https://jabrod.com/app/context). Sign in with your Jabrod account.</Note>

Context answers questions from the sources you give it: PDFs, Word documents, Markdown and text files, and web pages. Every claim in an answer carries a numbered citation that opens the passage it rests on. When the sources don't answer the question, Context says so instead of guessing.

```text Example
Q: How long do customers have to return an item?

A: Customers can return an item within 30 days of delivery [1]. Items bought
   on sale can only be exchanged, not refunded [2].

[1] Returns policy.pdf · Page 2
[2] Returns policy.pdf · Page 3
```

## How it works

1. **Ingest.** Each source is split into sections that remember where they came from ("Page 4", "Refunds › Exceptions"), then into passages, which are indexed for search.
2. **Retrieve.** A question is matched against your passages by meaning and by keywords, and the best six are kept.
3. **Answer.** A model writes the answer from those six passages only, citing each claim.

Sources live in **workspaces**. Each workspace is searched on its own.
