<Info>The Director is in Art Studio for Windows (JBD), and is part of [Art Pro](/art/jbd/pro-and-credits). It isn't in Art Studio's web Editor yet.</Info>

The Director is JBD's own agent. You write what you want, and it edits the clips you imported on your own timeline. It writes a plan, runs editing tools one step at a time in front of you, and looks at rendered frames before it reports back.

## What it does with your footage

Since version 1.2.0, ask for things like "cut the silences", "make a 30-second version", "trim the intro, add captions and put the music under it" or "cut this to the beat".

- **It listens before it cuts.** It reads what is said (clips without a transcript are transcribed on your computer first), finds pauses from the sound, and finds the beat of your music and the shot changes in long clips.
- **You see the edit first.** Cuts, trims, removals and reordering show as a preview: what goes, how long the edit will be, and a line for each change. Apply it or skip it.
- **Music sits under the edit.** Music goes on its own track, ends with the picture, fades in and out, and gets quieter whenever someone speaks.
- Picture and sound stay in sync on every track.

Video generation isn't available yet, so the Director edits footage you already have.

## Open it

The Director is a tab on the right side of Art Studio for Windows, next to the Inspector and Transcript. Its prompt box takes text and attached files. `Enter` sends; `Shift+Enter` starts a new line.

Inside the prompt box you pick:

- **Thinking model**: the model that plans and runs the edit.
- **Video model**: for generating clips, which isn't available yet.
- **Mode**: Ask, Auto edits or Plan.

## Modes

| Mode | What it does |
| --- | --- |
| **Ask** | Every tool asks before it runs. |
| **Auto edits** (default) | Edits run straight away. Anything that spends credits asks first. |
| **Plan** | Read-only. The Director looks and proposes, but changes nothing. Switch modes to run the plan. |


## Undo

One request is one undo step, named "Director: your request". To roll back everything the Director did for the last request, choose **Undo all** under the prompt box, or press `Ctrl+Z`.

## Chats

Each conversation is saved on your computer. The chats list shows them newest first; choose **New chat** to start fresh.

## Connectors

The Director can use tools from other programs over MCP, the same servers Claude Desktop runs. Add them in **Settings ▸ Connectors**. The file uses Claude Desktop's shape, so you can paste an existing `mcpServers` block:

```json connectors.json
{
  "mcpServers": {
    "notion": {
      "command": "npx",
      "args": ["-y", "@notionhq/notion-mcp-server"],
      "env": { "NOTION_TOKEN": "your-token" }
    }
  }
}
```

Connectors run as local programs over stdio. HTTP servers are not supported yet.

## Credits

The Director's work draws from your monthly [AI credits](/art/jbd/pro-and-credits#ai-credits). It shows the credits left under the prompt box.
