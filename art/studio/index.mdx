Open Art Studio at [art.jabrod.com/studio](https://art.jabrod.com/studio), or [install it as an app](/art/studio/install). Generation spends your AI credits, and each studio shows a generation's cost before you run it.

## What's in it

| Part | What it does |
| --- | --- |
| **Chat** | A general assistant, with your chat history in the sidebar. When it writes a generation prompt, the prompt appears as a card you can send to a board or a studio. |
| **Image Studio** | A prompt box with the model's options and credit cost, and every image you've made underneath. |
| **Voice Studio** | The same for voice lines from text. |
| **Video Studio** | Video generation isn't available yet. Upload clips instead: they work on boards, in the Library and in the Editor. |
| **Canvas** | Boards you build from nodes and connections. |
| **Library** | Every file you've uploaded or generated. **Open in Editor** opens a file in the Editor. |
| **Editor** | The JBD video editor in your browser. See [The Editor](/art/studio/editor). |

## Boards

Open **Canvas** to see your boards, or make a new one. A board is built from six kinds of node:

| Node | Key | Holds |
| --- | --- | --- |
| Prompt | `P` | Text. Connect it to a generator to fill that generator's prompt. |
| Image | `I` | A generated or uploaded image |
| Video | `V` | An uploaded clip |
| Audio | `A` | A generated voice line or an uploaded audio file |
| Note | `N` | Plain text for notes on the board |
| Export | `E` | The media wired into it, to download or edit |

- Drag image, video or audio files onto the board, or paste an image, to add them.
- `Ctrl+Z` undoes, `Ctrl+Shift+Z` or `Ctrl+Y` redoes, and `Ctrl+D` duplicates the selection.
- Boards save automatically. If the same board was saved somewhere else in the meantime, Art Studio reloads the latest version.

## From a board to the Editor

Connect the media you want into an **Export** node, then choose **Edit in the Editor** to cut it in [the Editor](/art/studio/editor), or **Download all** to save the files. Each node with media also has its own **Download**, so you can import files into [Art Studio for Windows (JBD)](/art/jbd/first-edit) too.

## Open source

Art Studio is published on GitHub at [Jabrod/art](https://github.com/Jabrod/art) under Apache-2.0. Accounts, generation and credits are on jabrod.com and aren't part of the repository.

Run it yourself:

```bash
git clone https://github.com/Jabrod/art.git
cd art
npm install
npm run dev        # http://localhost:3100/studio
```

On its own, Art Studio runs in local mode: boards and files stay in your browser, and chat and generation are switched off because they need a backend. To use another backend with the same API, set `NEXT_PUBLIC_ART_API`.
