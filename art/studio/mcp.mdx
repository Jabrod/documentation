<Note>The Art studio's MCP server isn't released yet. Its tools will be listed here when you can use them.</Note>

It will be a remote MCP server on jabrod.com, signed in with your Jabrod account, so Claude, Cursor and other clients can list your boards and generate images, video and voice into them. Generation will spend the same credits it does in the studio.

To drive the JBD editor from an MCP client today, use [JBD's MCP server](/art/jbd/mcp).
