<Note>The Evals MCP server isn't released yet. Its tools, inputs and outputs will be listed here when you can use them.</Note>

It will be a remote MCP server on jabrod.com, signed in with your Jabrod account, so Claude, Cursor and other clients can list your targets and test sets, create a test set, start a run, and read its report.

A coding agent will be able to run your test set after a change and read which cases regressed, without leaving the editor.
