The RAG API runs retrieval pipelines for your own applications. You create a pipeline on [agent.jabrod.com](https://agent.jabrod.com), add data to it, and query it over HTTPS with a pipeline API key. Jabrod handles chunking, embeddings, the vector store and retrieval.
