# Introduction

Welcome to **Jabrod** - the RAG as a Service platform. Jabrod allows you to build AI-powered applications with knowledge bases by providing a robust REST API for ingesting data, managing pipelines, and querying your knowledge.

## What is Jabrod?

Jabrod is a powerful backend for Retrieval-Augmented Generation (RAG). It handles the complexities of document chunking, embeddings, vector databases, and retrieval so you can focus on building your application.
