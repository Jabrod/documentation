# Usage

Monitor your API usage and check your current limits.

## Get Usage Stats

```typescript
const usage = await jabrod.usage.get();

console.log('Queries:', usage.queries);
console.log('Tokens:', usage.tokensUsed);
console.log('Documents:', usage.documentsUploaded);
```
