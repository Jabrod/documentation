# Usage

Monitor your API usage and check your current limits.

## Get Usage Stats

```typescript
const usage = await jabrod.usage.get();

console.log('Queries:', usage.queries);
console.log('Tokens:', usage.tokensUsed);
console.log('Chats:', usage.chats);
console.log('Documents:', usage.documentsProcessed);
console.log('Tier:', usage.tier);
```

## Check Remaining Limits

```typescript
const usage = await jabrod.usage.get();

console.log('Queries remaining:',
  usage.limits.queriesPerMonth - usage.queries
);
console.log('Storage remaining:',
  (usage.limits.storageBytes - usage.storageUsedBytes) / 1e9, 'GB'
);
```

## Usage Alerts

Jabrod sends email alerts at key usage thresholds:

- **50%** — Warning email to plan ahead
- **90%** — Critical warning to consider upgrading
- **100%** — Services paused, upgrade required

Upgrade anytime at [agent.jabrod.com/upgrade](https://agent.jabrod.com/upgrade).
