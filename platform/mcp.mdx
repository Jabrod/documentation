The Model Context Protocol (MCP) lets an AI app such as Claude Code, Claude Desktop or Cursor use another program's tools. JBD, Context and Evals have MCP servers today.

| Product | Server | Available | Setup |
| --- | --- | --- | --- |
| JBD | `jbd-mcp.exe`, a local program installed with JBD | Yes | [Connect JBD](/art/jbd/mcp) |
| Art studio | Remote server on jabrod.com | Not yet | [Art studio MCP](/art/studio/mcp) |
| Signals | Remote server on jabrod.com | Not yet | [Signals MCP](/signals/mcp) |
| Evals | `https://jabrod.com/api/mcp/evals` | Yes, on Evals Pro | [Connect Evals](/evals/mcp) |
| Context | `https://jabrod.com/api/mcp/context` | Yes | [Connect Context](/context/mcp) |

## Local and remote servers

- A **local** server is a program on your computer. The client starts it and talks to it over stdio. JBD's server is local because your projects are local.
- A **remote** server runs on jabrod.com and works on the data in your Jabrod account. The client connects to it over HTTPS and signs in with a personal API key from [jabrod.com/app/keys](https://jabrod.com/app/keys). Context and Evals have remote servers.

## Tool names

Clients show a tool with the server's name in front of it. If you add JBD's server as `jbd`, Claude Code shows `command_run` as `mcp__jbd__command_run`. Name each server after its product so the tools are easy to tell apart.
